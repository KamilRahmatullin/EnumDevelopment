Замените в проекте файлы build-protected.ps1, build-protected.bat и папку tools файлами из этого архива.
Скрипт использует официальный ASM 9.7.1, который загружается через Maven автоматически.
Требования: Maven в PATH и JDK 17+ (java и javac из одной установки).
Запуск: build-protected.bat или .\build-protected.ps1
